# PCL-001 — Owner details emit uncaught JavaScript errors

- **Severity:** Low
- **Environment:** Spring PetClinic at `http://localhost:8080/`; Chromium via
  Playwright MCP; manual UI run on 2026-11-12
- **Status:** Open

## Description

Opening owner detail pages emits uncaught JavaScript `TypeError` exceptions:
`Cannot read properties of null (reading 'style')`. Seven such errors were
recorded across the detail-page loads during this run. The owner details and
pet/visit flows remained usable, but the errors indicate page script code is
accessing a missing element.

## Steps to reproduce

1. Open Find Owners and search for an existing owner, or create a synthetic
   owner.
2. Open the owner's details.
3. Inspect the browser console.

## Expected vs. actual

- **Expected:** Owner detail pages render without uncaught JavaScript errors.
- **Actual:** The console reports `TypeError: Cannot read properties of null
  (reading 'style')` on owner detail routes. The page content remains visible.

## Impact

No functional failure was observed in the tested UI flows. This is a low
severity reliability issue; the affected script should guard or correct its
element lookup.
